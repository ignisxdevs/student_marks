BTech Student Record System
1. Problem Statement
Managing student information manually can be time-consuming and may lead
to errors, duplicate entries, or misplaced records. Finding or updating
a particular student's details can also become difficult as the number
of records increases.
The BTech Student Record System aims to provide a simple digital
solution for storing and managing student information. The system allows
users to add, view, search, update, and delete student records in an
organized manner.


2. Scope of the Project
The project focuses on basic student-record management through a simple,
menu-driven Python application.
The scope includes: - Storing essential student details such as roll
number, name, branch, and semester. - Adding new records and displaying
existing records. - Searching for a student using their roll number. -
Updating or deleting a student's record. - Saving records in a file so
that they remain available after the program is closed.
This is a beginner-level academic project. It does not include advanced
features such as user authentication, online access, or integration with
a college database.


3. Target Users
The intended users of the system are: - College students: To
understand and demonstrate basic student-record management. - Faculty
members: To maintain simple student information for academic or
demonstration purposes. - Project evaluators: To review the use of
Python programming concepts in a practical application.


4. High-Level Features
Add Student: Enter and save a new student's details.
View Records: Display the student records stored in the system.
Search Student: Find a record using the student's roll number.
Update Record: Modify the details of an existing student.
Delete Record: Remove a student record when required.
File Storage: Save records in a CSV file for later use.
Input Validation: Handle invalid inputs and notify the user when
a record is not found.

Menu-Driven Interface: Provide a simple menu to select the
required operation.
