B.Tech Student Record System --- Project Statement
1. Problem Statement
Students may need a simple way to enter their academic details and view
their marks, total, percentage, and grade together. Calculating these
values manually can take extra time and may lead to calculation errors.
The B.Tech Student Record System is a menu-driven Python program
that accepts a student's roll number, name, and marks in four subjects.
It calculates the academic results and displays them in a report-card
format. It also displays a simple forecast message based on the
student's percentage.


2. Scope of the Project
The project is limited to basic student detail and marks processing
through a command-line interface.
The scope includes: - Accepting a student's roll number and name. -
Taking marks out of 100 for Maths, Physics, Python Programming, and
Basic Electrical. - Storing marks in an integer array while the program
is running. - Displaying the student's details and marks. - Calculating
total marks and percentage. - Assigning a grade using the percentage
ranges defined in the program. - Displaying a simple next-semester
performance forecast. - Allowing the user to enter another student's
details or exit through the menu.
The current program does not provide permanent record storage, a
database, a graphical interface, or student login functionality. The
entered details are used to generate the report during the running
session.


3. Target Users
B.Tech students: To enter marks and view a calculated report
card.
Students learning Python: To understand how programming concepts
can be combined in a small application.
Teachers and project evaluators: To demonstrate or review the
use of Python fundamentals, functions, arrays, modules, and classes.


4. High-Level Features
Student Details: Accepts the student's roll number and name.
Subject Marks Input: Takes marks for four predefined subjects,
each out of 100.
Marks Array: Stores the entered marks in a Python integer array
during execution.
Report Card: Displays the student's details, marks, total marks,
percentage, and grade.
Grade Calculation: Assigns A+, A, B, C, or Fail according to the
percentage ranges in the program.
Performance Forecast: Displays a forecast message based on
whether the percentage is at least 75%.


Menu System: Lets the user enter student details again or exit
the program.
